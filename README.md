# Melody Cup – Virtual Piano Web

## プロジェクト概要 (Project Overview)

**Melody Cup** は、ピアノ学習と対戦ができる多機能ウェブサイトです。  
- 初心者からプロまで、学習・練習・対戦を段階的に行えます。  
- シンプルで使いやすいインターフェースで、音楽を快適に体験できます。  
- ウェブ上で再生されるピアノ音は **正確な音** で、本物のピアノのように学習できます。  

---

## 目標 (Goals)

- 科学的で体系的な学習・対戦サイトを構築する。  
- 美しく、使いやすいUI。  
- 年齢を問わず誰でも利用可能。  
- 「Now‑playing」機能の実装。  

---

## 成果 (Results)

### ユーザー向け (Người dùng)  
- 初心者〜上級者向けに学習・対戦コースを選択可能  
- ピアノ演奏と正確な音再生  
- 模範演奏の視聴  
- 好きな曲を選んで演奏  
- 同レベルのユーザーと対戦可能  
- 対戦ランキング表示  
- 楽譜表示で演奏確認  
- プレイリスト作成・名前変更可能  
- AIチャットで質問に応答  

### 管理者向け (Admin)  
- 学習・対戦コースとレベル作成  
- ユーザー管理（アクセス・登録）  
- 曲データ更新  
- 新しいプレイリスト作成・管理  
- ランキング毎週更新
